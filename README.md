# 🗄️ Banco de Dados (BD)

Repositório dedicado às atividades e aos exercícios desenvolvidos durante os estudos de Banco de Dados.

## 📋 Sobre o Projeto

Este repositório reúne atividades práticas realizadas durante as aulas, com foco na utilização da linguagem SQL para trabalhar com bancos de dados.

Os exercícios têm como objetivo aplicar os conceitos estudados, praticar comandos SQL e desenvolver conhecimentos sobre a organização e manipulação de dados.

## 🎯 Objetivos

* Praticar conceitos de Banco de Dados.
* Desenvolver e executar scripts SQL.
* Aprender a criar e manipular tabelas.
* Realizar consultas e operações em bancos de dados.
* Organizar e registrar as atividades desenvolvidas durante as aulas.

## 🛠️ Tecnologia Utilizada

* **SQL (Structured Query Language):** linguagem utilizada para criar, consultar e manipular dados em bancos de dados relacionais.

## 📂 Organização do Repositório

O repositório reúne arquivos e scripts SQL organizados para facilitar o acesso às atividades e a consulta dos conteúdos estudados.

## ▶️ Como Acessar as Atividades

1. Acesse o repositório no GitHub.
2. Baixe os arquivos ou consulte os scripts diretamente pelo navegador.
3. Abra os arquivos SQL em um editor de texto ou em uma ferramenta compatível com SQL.
4. Execute os scripts em um sistema de banco de dados compatível, quando necessário.

## 📚 Finalidade Educacional

Este repositório tem como finalidade registrar e organizar as atividades desenvolvidas durante os estudos de Banco de Dados, servindo como material de consulta e acompanhamento do aprendizado em SQL.
